4. Générer le paquet

Produit une archive .zip prête à déployer sur un hébergement statique (dossier dédié).

Déploiement et usage
  1. Dézippe l'archive générée dans un dossier dédié (ex. mon-circuit/).
  2. Dépose ce dossier sur un hébergement statique (GitHub Pages, Netlify, Cloudflare Pages…), à une URL du type https://mon-site.tld/mon-circuit/.
  3. Dans l'onglet 🧭 Suivi, colle cette URL pour télécharger le circuit — ou partage directement le lien …/terrain/?circuit=https://mon-site.tld/mon-circuit/ pour un chargement automatique.
  4. Une fois le téléchargement terminé (en ligne), le circuit reste disponible sans aucun réseau tant que l'app n'est pas désinstallée ou le circuit supprimé.
